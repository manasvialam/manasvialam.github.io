Projects

Agentic RAG assistant with an automated eval harness

Financial filings are long and easy to misquote. This agent decides what to look up across 1,000+ SEC filings stored in Qdrant, pulls the relevant passages and answers only from them, falling back from OpenAI to Anthropic if a call fails. A RAGAS harness scores every change, and it runs as a FastAPI and Docker endpoint at under 2 seconds p95.

92% groundedness and 89% retrieval precision@5 on RAGAS

Hybrid retrieval and reranking benchmark

Keyword search misses paraphrases, and vector search misses exact terms. This benchmark runs both, BM25 and bi-encoder embeddings, merges the candidates, and has a cross-encoder rerank them. It is measured over 10k queries, with an ablation that shows what each stage contributes.

nDCG@10 from 0.35 to 0.52 against BM25 alone

Forward-deployed automation agent

Qualifying inbound leads by hand is slow and inconsistent. This TypeScript agent runs a six-step workflow against the HubSpot API, from qualifying a lead to updating its CRM record, and hands the case to a person whenever it is not confident.

~70% less manual handling on a 200-lead test batch

Conversational intent and entity extraction

In a support or shopping chat, what the customer wants is spread across several turns. This pipeline classifies fine-grained intent and extracts multiple entities per conversation, using an open model adapted with instruction tuning and LoRA. vLLM with 4-bit and 8-bit quantization keeps it fast to serve.

91% intent accuracy, 87% entity F1, about 45% lower p95 latency

Preference-aligned conversational agent

Instruction tuning teaches a model the task, but not which of two answers people prefer. This project adds Direct Preference Optimization on pairs of preferred and rejected replies from multi-turn dialogue, so the model favours helpful, grounded answers. It is then quantized to 4-bit and served on vLLM.

31% fewer hallucinations and 2.1× the throughput

Earlier projects, with code
  • Kidney tumor detection. Classifies kidney CT scans as tumor or normal with a fine-tuned deep learning model. Experiments and data versions are tracked with MLflow and DVC so every run can be reproduced, and the model is served through a React and Docker web app.
  • Few-shot learning with prototypical networks. How do you recognise a new class from only a handful of examples? An encoder maps images into a space where each class is the average of its few examples, its prototype, and a new image takes the label of the nearest one. Trained episodically on CIFAR-100.
  • Sentiment analysis on Amazon reviews. Two ways of scoring the same Amazon reviews. VADER looks words up in a fixed sentiment dictionary, while RoBERTa reads each sentence in context, which matters for negation and mixed reviews. The project compares their outputs side by side.
  • Thompson sampling for ad selection. Which of ten ads should you show before you know which one works? Each ad keeps a Beta distribution over its click rate. Every round the model samples from all ten, shows the highest, and updates on the result, so it explores early and settles on the best ad later.
  • Movie recommendation system. Recommendations that need no user history. Each film's genres, cast and keywords are turned into TF-IDF vectors, and cosine similarity finds the films closest to the one you pick.
  • CRUD app on the MERN stack. A customer-details app built end to end: a responsive React front end, a RESTful Express and Node.js API, and MongoDB for storage, covering create, read, update and delete.
  • Tableau dashboards: customer analysis and netflix content. Two interactive dashboards. One breaks customer revenue down by state and month to show the strongest regions and seasonal trends. The other explores Netflix content by country, genre, rating and release year.
